# Catering Sales Data Analysis Project

# Overview
The project looks at 2 things: 
  1. The total revenue a business makes in a month.
  2. The revenue made in all the days in a month, and compares which days have the highest revenue and which ones have the lowest revenue.
  3. It then makes a conclusion based on the above goals.

# Setup
git clone https://github.com/Swiss-droid/catering-sales.git
cd catering sales
pip install -r requirements.txt

# Usage
python   Catering Bakery Analysis.py

# Data
Catering Bakery Monthly.csv contains the sales data collected everyday for a month.
Key Findings:
  1. There are more sales between Friday and Saturday, with Friday being the highest with an average sale of over R3500.
  2. Monday, Tuesday and Thursday have similar sales, with Monday being the highest with an average sale between R2000 and R2500.
  3. Wednesday and Sunday have the lowest sales, with Sunday being the lowest with an average sale of R1500.



catering_bakery_monthly.csv shows the results in a graph.
